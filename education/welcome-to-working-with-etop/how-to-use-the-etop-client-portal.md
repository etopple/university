# 🧭 How to Use the eTop Client Portal

## 🧭 How to Use the eTop Client Portal (portal.etop.tech)

#### Overview

The **eTop Company Portal** is your one-stop site for managing employee access, user updates, and IT support requests.\
Through the portal, you can **add or remove users**, **update contact details**, or **submit support tickets** — all with secure Microsoft 365 sign-in.

**Portal Address:** [https://portal.etop.tech](https://portal.etop.tech)

***

### 🔑 Signing In

1. Visit [**portal.etop.tech**](https://portal.etop.tech).
2. Click **Sign in with Microsoft**.
3. Use your work Microsoft 365 email and password.
4. Once signed in, you’ll see your company dashboard with tabs for **User Management** and **Ticketing**.

> 💡 _Access is limited to authorized decision makers for your organization. If you cannot sign in, please contact your company’s IT contact or email **helpdesk@etoptechnology.com** for assistance._

***

### 👤 Adding a New User

1. Go to **User Onboarding**.
2. Enter the new employee’s information:
   * First and last name
   * Job title and department
   * Manager (if applicable)
   * Start date and time zone
3. Leave the password field blank to have one automatically generated (recommended).
4. If the user replaces an existing employee, you can select that person to copy access and group memberships.
5. If hardware is needed, enter the computer’s **Service Tag** (found on top of the device).
6. Click **Submit**.
   * The new Microsoft 365 account will be created automatically.
   * Login details will be securely sent to the manager and/or user.

***

### 🧾 Removing a User

1. Go to **User Offboarding**.
2. Select the employee to remove.
3. Choose whether to:
   * Forward their email
   * Delegate OneDrive data
   * Set an out-of-office message
   * Schedule a specific date/time for removal
4. Click **Submit** to complete.
   * The account will be disabled and data secured automatically.

> ⚠️ _Be cautious when selecting “Cancel Calendar Invites.” This removes all meetings the user created._

***

### ✏️ Editing a User

1. Go to **Edit Users**.
2. Select an existing user.
3. You can update:
   * Name, job title, or department
   * Phone number
   * Microsoft 365 group memberships
4. Click **Save** to sync the changes across systems.

***

### 🎫 Viewing & Managing Tickets

1. Select the **Tickets** tab.
2. Review active and past support requests.
3. You can:
   * View ticket notes
   * Request a callback
   * Request ticket closure

All updates sync directly with the eTop Service Desk for faster turnaround.
