# ScreenConnect on MacOS

Later versions of MacOS secure your system by reducing the items that can access your screen and items.&#x20;

This article will provide the necessary steps to allow eTop techs to use ScreenConnect to view and control your computer.

Note: only allow apps like ScreenConnect on your system if you trust the source.&#x20;

1. Click on System Settings (formerly System Preferences)
2. Go to **Privacy and Security > Accessibility** and enable the item with "connectwisecontrol" and the red square icon\
   \
   ![](<../../../../../.gitbook/assets/image (105).png>)
3. Go to **Privacy & Security > Screen & System Audio Recording** and enable the item with "connectwisecontrol" and the red squares icon\
   ![](<../../../../../.gitbook/assets/image (103).png>)
4. At connection, you might receive an alert to allow connection:\
   ![](<../../../../../.gitbook/assets/image (106).png>)\
   Select Allow.
