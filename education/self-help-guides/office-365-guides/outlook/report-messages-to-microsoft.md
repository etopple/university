# 🚩 Report messages to Microsoft

Reporting phishing or junk mail is crucial for maintaining digital security and preserving the integrity of your personal information. By alerting Microsoft to these threats, you help them to identify and block malicious actors, preventing potential data breaches and financial fraud. Additionally, reporting these incidents aids in creating a safer digital ecosystem for all users, as it assists in refining spam filters and enhances the effectiveness of security protocols across platforms.

**Here are the steps for reporting messages that are Phishing and Junk**

1. Select a message that is not in the Junk Email folder
2.  Click Report, then select the correct option of Phishing or Junk

**Here are the steps for reporting messages that were marked as junk but are not junk**

1. Select a message that is in the Junk Email folder
2. Click Report, then select "Not Junk"\
