---
title: "Yubikey setup for Microsoft MFA"
description: An alternative to Microsoft Authenticator
---
Sometimes it makes more sense to use a hardware USB key for multifactor authentication. Here are the instructions for configuring that:

1. Sign into your Microsoft Account page [https://account.microsoft.com/account](https://account.microsoft.com/account)
2. Select Security info on the left
3. Select Add sign-in method\
   ![](</.gitbook/assets/image (138).png>)
4. Select Security key\
   ![](</.gitbook/assets/image (139).png>)
5. Click USB device\
   ![](</.gitbook/assets/image (140).png>)
6. Click Next\
   ![](</.gitbook/assets/image (141).png>)
7. Plug in your security key to the USB port on your computer.
8. If required, you will be prompted to configure a PIN for the security key. Create a number PIN that you can remember.
9. Put your finger on the gold disc on the Yubikey. \
   ![](</.gitbook/assets/image (142).png>)

Your account is now protected with secure Multi-factor authentication

More information can be found here: \
[https://www.yubico.com/works-with-yubikey/catalog/microsoft-accounts/](https://www.yubico.com/works-with-yubikey/catalog/microsoft-accounts/)\
